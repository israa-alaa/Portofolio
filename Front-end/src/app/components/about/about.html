About Me

Who am I?

I am a dedicated Front-End Developer with experience in building responsive and interactive websites. I enjoy the process of bringing designs to life and making sure every pixel is in the right place. My foundation in HTML, CSS, and JavaScript allows me to craft websites that are both functional and visually appealing.

My journey in web development started with curiosity about how websites work, and it quickly turned into a passion. I have worked on various projects that helped me understand the importance of user experience and clean code architecture. I also use tools like Figma and Canva for design, and Postman for API testing.

When I'm not coding, you can find me exploring new design trends on Figma, contributing to open-source projects on GitHub, or learning about the latest advancements in web technologies. I believe that good design and clean code go hand in hand to create the best digital experiences.
